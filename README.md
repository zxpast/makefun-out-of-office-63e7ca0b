# The Painfully Honest Out-of-Office

make.fun entry for **The Painfully Honest Out-of-Office**
(`u-po-pu-the-painfully-honest-out-of-office-63e7ca0b`) — a program that writes
one brutally honest but still polite out-of-office auto-reply.

## The entry

> I'm away until Monday, and your email joins the unread pile I answer strictly in order of how guilty each sender makes me feel.

**127 characters** (127 bytes, one sentence, UTF-8, no trailing newline).

The private truth it admits: replies are triaged by guilt, not by priority.
The twist lands in the last words; the narrator is the butt of the joke.

## How to run

Node 22, standard library only, deterministic, no network:

```sh
node main.ts
```

It writes the line above to `/output/entry.txt` (or to `./output/entry.txt`
when `/output` is not writable, e.g. a local run). Two runs produce
byte-identical output.
